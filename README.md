# 嬰兒哭聲偵測播放器

開啟麥克風持續監聽，偵測到寶寶哭聲或哀叫時，自動播放指定的安撫音檔。
純前端、零依賴，麥克風聲音只在本機即時分析，不錄音、不儲存、不上傳。

- **線上使用**：https://erich0793.github.io/claude-on-the-net/
- **使用說明**（操作步驟、設定建議、疑難排解）：`guide.html`（頁面右上角「📖 使用說明」）

## 主要功能

- **AI 聲音分類**：內建 YAMNet（TFLite WASM，4MB，同源自架、離線可用）即時辨識
  嬰兒哭聲／哀叫，並以「大人語音否決」大幅減少誤判；載入失敗自動退回傳統 DSP 偵測
- **雙模式偵測**：僅哭泣（持續哭聲累積）／哭泣＋哀叫（20 秒內 2 聲合格短聲）
- **聲學判定**：自相關法量測基頻（嬰兒 250–1000Hz），自動排除大人講話（85–255Hz）；
  音量門檻相對背景噪音自動校正，開始監聽含 3 秒環境校準
- **音檔管理**：本機記憶（IndexedDB）、瀏覽器內剪輯（位元組切片解碼，大檔不爆記憶體）、
  下載匯出（跨裝置共用）
- **播放控制**：循環播放至指定時長、哄睡音量淡出（Web Audio 增益）、手動停止後 30 秒冷靜期
- **iOS 韌性**：處女元素池（每次警報用一顆手勢解鎖過、從未播放的全新元素，
  用完即棄，確保路由到藍牙／AirPlay 音響且不劣化音質）、播放前先釋放麥克風、
  播放結束後深度音訊重置（關閉並重建全部音訊資源，歸位 iOS 輸出路由，
  同時保留使用者手勢的播放授權以維持音質）、螢幕喚醒鎖、麥克風中斷看門狗與
  自動重連、所有麥克風請求皆設逾時（iOS 卡住時不會 reject，只會永遠不回來）、
  啟動流程重入防護、播放管線卡死自動偵測與脫困
- **觸發次數無上限**：元素池用完後由「熱身元素」接手——它們跟著保連脈衝一起發出
  17.5kHz，播放授權每 4 分鐘被真實播放刷新一次，用完再換回保連訊號重回輪替
  （無使用者手勢建立的元素會被 iOS 永久拒播，故不能靠程式補鑄新元素）
- **音響支援**：脈衝式保持連線（每 4 分鐘發送 5 秒 17.5kHz 訊號防閒置斷線；
  錄音期間 iOS 不會將網頁音訊送往外部音響，故採脈衝設計）
- **背景偵測**：退到背景時偵測改由計時器驅動（rAF 會被凍結），每分鐘留一行心跳
  與幀數以供驗證
- **事件紀錄**：觸發、短聲、麥克風離線秒數、播放被擋的錯誤名稱與元素身分、
  保連脈衝時間線、頁面載入、診斷統計皆留時間戳（localStorage，上限 400 行且
  超量時優先淘汰診斷行），供隔日回顧與調校

## 本機開發

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000（麥克風僅在 https/localhost 可用）
```
